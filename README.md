# fakerealnewsdetection
This project uses machine learning to detect fake news using logistic regression and TF-IDF features, developed and trained in Google Colab. 

# 🎯 Project Title

This project applies machine learning techniques to detect fake news using TF-IDF feature extraction and Logistic Regression. The model is trained and evaluated in Google Colab, demonstrating effective text classification for distinguishing between real and fake news articles.

## 🚀 Features
- Data preprocessing using pandas and numpy  
- Model training with scikit-learn  
- Visualization with matplotlib  
- Implemented and tested in Google Colab
